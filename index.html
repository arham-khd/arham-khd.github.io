Meta-Decoding QEC: Decoder Routing Benchmark

Implemented a software benchmark for routing across a portfolio of decoders under accuracy, latency, and switching-risk constraints. The project is framed as a software/ML systems problem applied to quantum error correction.

  • Built a Python experiment pipeline with six decoder implementations, controlled seeds, logs, evaluation tables, and reproducible plots.
  • Designed diagnostics for oracle upper bounds, switching risk, specialist behavior, bootstrap confidence intervals, random-switch baselines, and ablations.
  • Validated conservative routing strategies that recover cases missed by the best fixed decoder while avoiding uncontrolled harmful switches.
