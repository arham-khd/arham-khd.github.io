# Arham K — GitHub Pages Portfolio

A static GitHub Pages portfolio for showcasing active projects, academic achievements, skills, and contact links.

## Files

- `index.html` — main website content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and project filters
- `assets/` — place your CV PDF, profile image, and other assets here

## Deploy on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of the repository.
3. Go to repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`, then save.
6. Your site will be published at `https://YOUR-USERNAME.github.io`.

## Things to edit first

Search for these placeholders and replace them:

- `your.email@example.com`
- `YOUR-USERNAME`
- `YOUR-LINKEDIN`
- Project repository links
- `assets/Arham_K_CV.pdf`
